# Portfolio case

Читатель: артдир / лид продукта, 10+ лет. Три минуты решить, читать ли дальше; тридцать — на глубину.

Сильный кейс: какую проблему и для кого → какая гипотеза и чем проверила → какое решение и почему не другое → что изменилось или честно не замерила. Не отчёт «прошла все этапы» и не галерея экранов.

## Среда и файлы

Работай в `design/03-content/`. Вход: `design/01-research/outputs/research-digest.md` (+ PRD, если дайджест ссылается). Внутренности `01-research/` не читать, пока нет дыры в дайджесте.

| Файл | Роль |
|------|------|
| `copy/case-{id}.md` | Слои A + B, ключи сайта |
| `copy/{slug}.md` | Живое исследование. Новые факты — сначала сюда |
| `strategy/case-writing-template.md` | Канон полей A. Читать при заполнении A, не целиком заранее |
| `outputs/content-package.md` | Строки ключей после B |
| `shared/content.js` | Страница. Синк только если задача про сайт |

Карта ключей и short/long: [page-map.md](references/page-map.md). Голос и запреты: [voice.md](references/voice.md). Плохо / хорошо: [examples.md](references/examples.md).

## Порядок

Скопируй чеклист и веди его.

```
- [ ] 1. id кейса, card.*, ключи case.{id}.*
- [ ] 2. Факты: дайджест + owner. Пустое поле A — вопрос, не выдумка
- [ ] 3. Слой A в copy/case-{id}.md (ярлыки только здесь)
- [ ] 4. Живой copy/{slug}.md, если исследование длиннее трёх инсайтов
- [ ] 5. Слой B в ритме SLA, без ярлыков A
- [ ] 6. content-package + при публикации сайт — content.js
- [ ] 7. Показать текст пользователю (короткая и/или длинная — как просил)
```

**1. Идентичность.** `card.{x}.title/meta/description` и `case.{id}.*`. Описание карточки может быть каноном макета (даже 4 фиксированные строки) и не обязано пересказывать кейс.

**2. Факты.** Бери только то, что есть. Чужую цифру (клики кампании до экрана) не класть в результат UI. n=2 интервью — направление, не опрос рынка. Коридор / A/B / tree-test — только если владелец подтвердил.

**3. Слой A.** Таблица полей из шаблона. Плюс четыре ответа Mentory (только в A): проблема и для кого; гипотеза «изменение → эффект, потому что инсайт, проверим через метрику»; на какую метрику целились (замерили / нет); что в системе кроме UI. JTBD, user story, таблица «взяли / отложили» — только A.

**4. Живое исследование.** Полные интервью, матрица, боли, открытые вопросы — в `copy/{slug}.md`. На странице секция «Исследование» — сжатие, не простыня. Новые данные: сначала `{slug}.md`, потом сжать в `analysis_body`.

**5. Слой B — ритм [SLA 3→30](https://faithful-pink-98c.notion.site/SLA-3-30-16dd55a60207806c9bbcd56968f2e633).** Подписи-якоря, короткие абзацы, кадры с подписью «на что смотреть». Не тур по экранам.

| Блок | Что писать |
|------|------------|
| Вводные | Продукт + какой кусок в кейсе. Затем **Цель**, **Аудитория**, **Критерии успеха**. Нет замера в герое — критерий и «не замерила», не чужой % |
| Контекст | Одна сцена «до» (что открыто, Excel/файл, цена). Не повторять вводные. Long-only |
| Исследование | Бенчмарки (одно дыхание) → метод и n → выводы: работа, ценности, барьеры, что не копировать. Long-only |
| Гипотезы | Коротко: одно решение + провал теста + одно «не стала». Long: ещё 1–2 выбора. В тесте писать, **что не поняли** |
| Выводы | Три абзаца: замер или честный стоп; провал/компромисс; что сделала бы иначе. Не копировать вводные |

`## Заголовок` в теле секции рендерится как подзаголовок. Во вводных так задаются Цель / Аудитория / Критерии.

**6. Публикация.** Строки в `content-package.md`. Если страница живая — те же строки в `shared/content.js`, висячие предлоги через `fixHangingPrepositions`. Тесты, которые лочат ключ, обновить под новый канон, не наоборот.

**7. Показ.** «Покажи текст» = слой B как на странице. «Расширенная / длинная» = B + полный `{slug}.md` в блоке исследования. Не подменять одно другим молча.

## Gate (B готов)

- [ ] Первое лицо, одна мысль на предложение, первая фраза блока = смысл
- [ ] В B нет ярлыков A (`JTBD`, `as-is`, `dual-mode`, `H2`, `primary`)
- [ ] Результат или честный незамер — во вводных, не извинение первым абзацем
- [ ] Цифра атаки/кампании не выдана за эффект дашборда
- [ ] Короткая читается без исследования; длинная не дублирует те же ярлыки сжатым PRD
- [ ] Прочитано вслух: так скажешь артдиру

## Стоп

Пустое «доказательство», «ограничение v1», n теста, якоря лет — вопрос владельцу. Не закрывать выдуманным Impact/Effort, «опросом 40+» или SLA «было X стало Y», если замера нет.
