# Примеры

Эталон ритма страницы: [SLA 3→30](https://faithful-pink-98c.notion.site/SLA-3-30-16dd55a60207806c9bbcd56968f2e633) — цель / аудитория / критерии до процесса; исследование = бенчмарк + метод/n + выводы; в тесте — что не поняли. Метрику в заголовок — только если замерили. У SLA «3 часа → 30 минут»; без замера так не писать.

## Слой B: нейрослоп vs речь

Плохо (склейка полей A):

> InnoPhish — awareness и устойчивость к социнженерии. Миссия: актуальная картина «обучение + атаки» без dual-mode. Результат: as-is EvilGo → сводный дашборд; вкладки «Атаки» / «Обучение». Макет → прод; повторно не замерили.

Хорошо (те же факты):

> InnoPhish учит сотрудников не вестись на фишинг. Кейс — сводная страница для ИБ, не весь продукт.
>
> Цель. Закрыть доклад без Excel и ставить курсы с актуального среза.
>
> Критерии успеха. Доклад без склейки. Курс с топа. PDF по кнопке. После запуска время доклада не замерила.

## Цифры

Плохо: «дашборд снизил клики по фишингу на 60%».  
Хорошо: «в одной кампании до сводки около 60% перешли по ссылке. Это про аудиторию, не про экран».

Плохо: «время доклада −50%» без замера.  
Хорошо: «целилась в скорость доклада. После запуска не замерила. Есть тест макета, не бой».

## Исследование на странице

Хорошо: «говорила с двумя специалистами ИБ. Это направление, не рынок» + три вывода + что не копировать с рынка.
