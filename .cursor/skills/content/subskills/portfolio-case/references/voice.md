# Голос слоя B

Прямая фраза важнее красивой. Метафора и «умная» плотность — чтобы автор выглядел взрослее; читатель тогда работает за него.

## Пиши

- Первое лицо. Факты — прошедшим, устройство экрана — настоящим.
- Одна мысль на предложение. Без цепочек через `;` и `→` в B.
- Первая фраза блока = смысл (Krug). Дальше можно не читать.
- Слова, которые произносят вслух. Эталон плотности: «очки в вакууме», «сюда поместится шкаф».
- Один факт — в одном месте.
- Кавычки «ёлочки». Висячие предлоги — NBSP (`shared/typography.js` / правило `30-russian-typography`).

## Не пиши на сайте

Ярлыки исследования: `as-is`, `to-be`, `org-сводка`, `dual-mode`, `JTBD`, `продуктовое мышление`, `primary` / `secondary`, `H1`–`H5`, `J1`, `fail→обучить`, `traffic-light`, `MVP` без нужды.

Внутри абзаца не ставить «Миссия:», «Инсайты:», «Методы:». Навигационный заголовок секции можно («Исследование»).

Нельзя: повтор героя в каждой секции; «к сожалению, метрик нет» первым абзацем; горящие глаза, мат, шутки «разрядить»; канцелярит; прямые `"` вместо ёлочек.

В тесте и выводах писать, **что люди не поняли**, не только что зашло.

## Mentory — в A, в B без ярлыков

Четыре ответа должны читаться в B:

1. Какую проблему и для кого.
2. Что изменила и почему (инсайт, не вкус).
3. На какую метрику целилась. Нет замера — имя показателя и «не замерила».
4. Что кроме экрана: Excel, права, легаси, файл.

Методы (коридор, A/B, опрос) — одно предложение в исследовании, и только если они были.
