# style-decompose — декомпозиция стиля с Dribbble в систему

## Среда

Группа `ds`, среда `02-design-system/` (визуальные foundations).

Артефакты по умолчанию в **корне рабочего проекта** — так связан с `build/design-loop`:
- `STYLE_GUIDE.md`, `moodboard/`, `structure_selects/`

После утверждения копия токенов и принципов — в
`02-design-system/foundations/style-guide.md`. Продуктовый контекст — из
`01-research/outputs/prd.md` или `research-digest.md`, не выдумывается.

Превращает понравившийся UI/студию в **переиспользуемую систему правил**, а не в копию обложки. Это вход в флоу «дизайн-система за один присест».

## Принцип
Кейс на Dribbble — это **серия экранов**, а не одна обложка. По огрызку систему не соберёшь. И ещё: у топовых студий ~70% впечатления даёт **подача** (свет/угол/грейд), а не сам UI. Поэтому раскладываем стиль на **два слоя**:
- **Слой A — подача/рендер** (свет, глубина, грейд, материал) — для обложек/hero.
- **Слой B — структура UI** (сетка, иерархия, компоненты, типографика, цвет) — для рабочих экранов и генерации.

## Шаги
1. **Собрать список шотов.** `curl` профиля Dribbble отдаёт обложки и ссылки на шоты. Профиль обычно проходит, отдельные шоты — за AWS WAF.
2. **Зайти в КАЖДЫЙ кейс через реальный браузер** (Claude in Chrome) — мимо WAF. Прокрутить шот **до конца** (триггерит lazy-load) и собрать все изображения **выше блока «More by»**. Отфильтровать залётные обложки соседних шотов (у них ID userupload далеко от ID основного кадра) и служебные баннеры автора.
   - JS-тул браузера блокирует вывод URL с query — резать по `split('?')[0]`.
   - **Не слать JS-экстракцию в том же `browser_batch`, что и `navigate`** — гонка «Inspected target navigated or closed». Навигировать → подождать ~0.8–1.5 сек → отдельным вызовом извлекать (или ретрай-цикл в JS, ждущий появления `img[userupload]`).
   - Если шот вернул пусто (WAF-челлендж 202) — повторить навигацию через 1–2 сек; обычно со второго раза проходит.
   - Брать последние 10 кейсов (или сколько просят); каждый = 2–8 кадров.
3. **Скачать полноразмерные оригиналы** (CDN `cdn.dribbble.com` не за WAF) в `moodboard/<studio>/<NN_slug>/`.
4. **Отсмотреть кадры глазами** (Read изображений) — без этого декомпозиция будет общими словами.
5. **Собрать `STYLE_GUIDE.md`** по структуре:
   - Главный инсайт (два слоя).
   - Слой A: камера/кадр, глубина резкости, свет, грейд, материал, фон.
   - Слой B: иерархия (один герой), layout-системы, каталог компонентов, дата-виз, иконография.
   - **Композиция и метрики (ОБЯЗАТЕЛЬНО — иначе генератор откатится в свой дом-стайл).** Снять с кадров и зафиксировать ЯВНЫМИ значениями: точные веса шрифта и тип-шкалу; **радиусы** (часто крупный superellipse, не дефолт 16–24px); внутренние отступы и интервалы; пропорции элементов; **как определяется край** — почти всегда СВЕТОМ (блик + тень + люминесценция), а НЕ нарисованным бордером; асимметрия/воздух композиции. Без этого слоя стиль не угоняется — выходит «опять то же, что обычно генерит модель».
   - Типографика (шрифты-кандидаты, формат числа-героя, mixed-weight, микро-лейблы).
   - Цвет (один hue владеет кадром, один акцент <5%, десатурация, светлая/тёмная).
   - Структура серии (hero → детали → in-hand → CTA).
   - Почему работает (перцептивные принципы).
   - Playbook воспроизведения (генерация / реальный UI / конвейер подачи).
   - Анти-паттерны (вкл. **нарисованные бордеры** и **дом-стайл генератора**) + чек-лист.
6. **Отобрать 6–7 «структурных» кадров** в `structure_selects/` (те, что показывают IA/сетку/компоненты, а не арт-кропы) — их прикладывать к дизайн-генератору.

## Память (правила)
- [[feedback_scrape_full_galleries]] — заходить в каждый кейс, скроллить до конца, кейс = серия.
- Категоричные тезисы из веб-ресёрча не тащить вслепую — синтезировать и заземлять.
- Курсив не использовать ([[feedback_no_italic]]).

## Принцип
Каждый прогон — **с нуля от свежего референса**, который дал пользователь. Не опираться на ранее собранные STYLE_GUIDE/мудборды других прогонов как на основу — только текущий референс ([[feedback_stream_from_scratch]]).

## Выход
- `moodboard/<studio>/` — кадры по кейсам + `sources.md`.
- `STYLE_GUIDE.md` — декомпозиция (главный артефакт, дальше идёт в `design-loop`).
- `structure_selects/` — 6–7 кадров под дизайн-генератор.
