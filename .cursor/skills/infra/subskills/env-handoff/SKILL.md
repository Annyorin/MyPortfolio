# Handoff между средами

## Когда применять

Текущая среда не может завершить задачу, потому что нужного нет в чужом `outputs/`.
Если артефакт там уже есть — контракт не нужен, просто прочитай его.

## Шаги

1. Определи среду-исполнителя по [`_shared/registry.md`](../../../../../design/_shared/registry.md).
2. Возьми следующий свободный номер: посмотри имена файлов в `_shared/contracts/`.
3. Создай `_shared/contracts/<NNN>-<from>-to-<to>.md` по формату из
   [протокола](../../../../../design/_shared/contracts/README.md).
4. Заполни «Зачем» так, чтобы исполнитель принял решение **не читая** твою среду.
5. Останови работу над заблокированной частью задачи и сообщи пользователю,
   что нужен запуск среды-исполнителя. Не выполняй чужую работу сам.

## Исполнение контракта

Работая как среда-исполнитель:

1. Выполни работу целиком внутри своей среды.
2. Опубликуй результат в свой `outputs/`.
3. Заполни в контракте раздел «Результат» ссылкой на артефакт и краткой сводкой.
4. Поставь `status: done`. Готовый контракт не редактируется — на правки заводится новый.
