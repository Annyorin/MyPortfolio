# Figma MCP: процедуры синхронизации

Детали к [SKILL.md](SKILL.md). Читать при выполнении синка, а не при каждом обращении к Figma.

## Проверка целостности перед работой

Перед любой задачей, затрагивающей Figma:

```
- [ ] whoami отработал, аккаунт совпадает с ожидаемым
- [ ] fileKey из ссылки найден в 02-design-system/figma/registry.md
- [ ] среда-владелец файла совпадает с текущей средой
- [ ] для среды 4: mirrored-version зеркала == version манифеста среды 2
```

Любой невыполненный пункт останавливает работу до его закрытия.

## Синк «Figma → текст» (среда 2)

1. `get_metadata` по узлу библиотеки — получи список дочерних узлов.
2. Сопоставь узлы со строками `registry.md`:
   - есть в Figma, нет в реестре → новый компонент, завести файл и строку;
   - есть в реестре, нет в Figma → удалён или переименован, пометить `deprecated`
     и записать дрейф;
   - есть в обоих → сверить варианты и состояния.
3. Для каждого изменившегося узла: `get_variable_defs`, затем `get_design_context`.
4. Обнови файл компонента в `components/`, строку в `registry.md` и `components/INDEX.md`.
5. Запиши операции в `sync-log.md`.
6. Подними `version` в `outputs/ds-manifest.md` и обнови его таблицы.

Версия манифеста — semver по смыслу изменений:

| Что произошло | Разряд |
|---------------|--------|
| удалён или несовместимо изменён компонент, переименован токен | major |
| добавлен компонент, вариант или токен | minor |
| уточнено описание без изменения состава | patch |

## Синк «текст → Figma» (среда 2)

1. `search_design_system` по назначению компонента.
2. Найдено — изменяй существующий узел через `use_figma`. Не найдено — создавай новый
   и сразу заводи строку в `registry.md` с полученным node-id.
3. Отрази изменение в файле компонента, затем в `sync-log.md`, затем в манифесте.

Порядок обязателен: сначала Figma, потом текст, потом манифест. Обратный порядок
даёт реестр, ссылающийся на несуществующие узлы.

## Сборка экрана (среда 4)

1. Сверь `mirror/ds-mirror.md` с манифестом среды 2. Разошлись — обнови зеркало.
2. Проверь, что все компоненты спецификации экрана есть в зеркале. Нет — контракт
   в среду 2, сборка на паузе.
3. `search_design_system` для получения актуальных ссылок на компоненты.
4. `use_figma` — сборка экрана в продуктовом файле.
5. Запиши строку в `screens/SCREEN-MAP.md`: экран, node-id, версия зеркала, дата.
6. Запиши строку в `outputs/build-log.md`.

## Разрешение дрейфа

Дрейф — расхождение между узлом Figma и его текстовым описанием.

| Ситуация | Источник истины | Действие |
|----------|-----------------|----------|
| Компонент изменён в Figma вручную | Figma | подтянуть в текст, поднять версию |
| Текст описывает то, чего нет в Figma | текст | либо создать узел, либо удалить описание — решает пользователь |
| node-id в реестре не резолвится | Figma | пометить строку `deprecated`, найти замену |
| Экран собран на устаревшем зеркале | манифест | пересобрать экран после обновления зеркала |

Неразрешённый дрейф не переносится на следующую задачу: он либо устранён, либо
явно вынесен пользователю как решение.

## Ошибки записи через Plugin API

Детали для `use_figma` и скиллов `handoff-to-figma`, `figma-to-proto`.
Канон инвариантов: [`_shared/figma-code-invariants.md`](../../../../../design/_shared/figma-code-invariants.md).

| Ошибка | Правильно |
|--------|-----------|
| `resize(W, 0)` на auto-layout | Для HUG: `primaryAxisSizingMode = "AUTO"`, не resize по этой оси |
| TEXT без стиля | Всегда `setTextStyleIdAsync` / `textStyleId`, не raw `fontName` + `fontSize` |
| `layoutSizingHorizontal: "FILL"` до добавления в родителя | FILL — только **после** того, как узел стал ребёнком |
| Шрифт `"SemiBold"` | Inter использует `"Semi Bold"` (с пробелом); перед текстом — `loadFontAsync` |
| Variable alias как строка | `{ "type": "VARIABLE_ALIAS", "id": "<variableId>" }` |
| SVG-иконки через `vectorPaths` | `createNodeFromSvg(svgString)` — dasharray, градиенты, clipPath |
| `combineAsVariants(arr, page)` | В массиве только COMPONENT, не FRAME |
| `await` внутри callback | Оборачивающая функция должна быть `async` |
| `figma.currentPage = …` | Read-only; использовать `figma.setCurrentPageAsync(page)` |

## Лимиты и батчи

- Код в одном вызове `use_figma` — порядка **~15 KB**. Большие операции **дробить
  на батчи** с сохранением прогресса в `02-design-system/figma/mirror-map.json`.
- Student plan: shared libraries недоступны — компоненты только внутри файла.
- Локальные шрифты могут не появиться в `listAvailableFontsAsync()` — fallback + запись
  в `sync-log.md`.

## Диагностика ошибок

| Симптом | Причина | Что делать |
|---------|---------|------------|
| ошибка авторизации | нет OAuth-сессии | `mcp_auth`, ссылка пользователю, затем `whoami` |
| файл недоступен при рабочем `whoami` | нет прав на файл или чужой план | сверить план из `whoami` с владельцем файла |
| rate limit | исчерпан лимит 10/мин или 200/сутки | остановиться, сообщить остаток работы |
| `use_figma` не пишет | подключён desktop-сервер | переключиться на remote `https://mcp.figma.com/mcp` |
