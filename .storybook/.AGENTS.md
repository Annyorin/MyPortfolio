# Каталог: .storybook/

## Назначение
Конфигурация Storybook 8 (`@storybook/html-vite`) для каталога DS.

## Файлы

### main.js
- stories glob `../stories/**/*.stories.js`
- framework `@storybook/html-vite`
- Vite alias `@ds-assets` → `ds-showcase/assets`

### preview.js
- import `../ds-showcase/css/tokens.css`
- import `../ds-showcase/css/components.css`
- backgrounds: светлый page `#fefefe` (как витрина)

## Зависимости
- `stories/`
- `ds-showcase/`
- корневой `package.json` / `vite.config.js`
- peer для Storybook 8 manager: `react`, `react-dom` (devDependencies)
