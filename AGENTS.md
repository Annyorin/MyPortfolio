# Оркестратор (Cursor)

Корневой агент этой сессии — координатор, не исполнитель предметной работы.

1. Прочитай `CLAUDE.md` и `01_orchestrator.md`.
2. Для дизайн-задач внутри этапа дизайна следуй `design/AGENTS.md`, но пути сред — `design/<env>/`.
3. Делегируй субагентам Cursor (`Task` / Agent) с теми же именами, что в `.claude/agents/`.
4. Скиллы дизайна — только роутеры в `.cursor/skills/`, затем один подскилл.
5. Не читай `design/_shared/reference/` без запроса человека.

Если задача целиком про одну дизайн-среду и пайплайн разработки не нужен — маршрутизируй сразу в `designer` и нужный субагент, без аналитика.
