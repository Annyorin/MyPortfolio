# Матрица конкурентов — атаки / реакции / обучение

Только рынок. Колонки «Мы» нет — план «А» в `_matrix.md`.

**Прямые** — SAT + фишинг + аналитика.  
**Гибрид** — SA с полноценным LMS-контуром (EALP).  
**Косвенные** — симуляция без обучения **или** LMS / процесс без метрик атак.

Легенда: ✅ есть / ◐ частично / ❌ нет / ? не видно публично.  
*Курсив в шапке* = косвенный или гибрид.

## Белые пятна

1. **РФ LMS сильны в обучении** (особенно iSpring: балл, время, филиалы) и **пусты по атакам** — закрывают HR-срез «А», не primary ИБ.
2. **Гибрид EALP** бьёт в «LMS + фишинг в одном», но публично слабо виден Risk / реакции уровня Hoxhunt.
3. **Прямые SA** редко показывают LMS-глубину (SCORM, 360, филиты) на сводке — берут контент ИБ, не HCM.
4. As-is **Excel** остаётся косвенным «дашбордом» ИБ, пока атака и обучение в разных продуктах.

## Паттерны взять (обучение)
- Статусы + балл + время + срез по оргструктуре → **iSpring**.
- HCM-контекст назначений → **WebTutor**.
- Не рвать фишинг и курсы по двум вендорам без моста → урок **EALP** / боль рынка.
- HR-only срез без атак → любой зрелый РФ LMS.

## Анти-паттерны

- Игнорировать Excel как реального конкурента workflow.
