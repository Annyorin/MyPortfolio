## Белые пятна рынка (относительно задачи «А»)

1. **Единый первый экран «обучение + атаки + Risk» без подмены отчётами** — у лидеров Risk/PPP сильны, но РФ-игроки часто жёстко фиксируют главную (Phishman) или слабо раскрывают виджеты (Solar, ASAP).
2. **Связка «кликнул → назначили → завершил» как видимый путь на сводке** — у KnowBe4/Антифишинг/ASAP есть элементы; в as-is интервью пути нет; Gophish/LMS разрывают цикл.
3. **Раздельные срезы HR (обучение) и SOC (уязвимые + инциденты) без dual-mode** — решение v1 «А»; рынок редко даёт оба среза явно (KnowBe4 Executive templates; Антифишинг SIEM; LMS HR-only).
4. **Actionable summary (назначить курс с дашборда)** — ярко у Антифишинг; не везде на первом экране.
5. **ФИО-топ на сводке + сравнение подразделений без traffic-light** — VAP/рейтинги у конкурентов есть; жёсткий порог «плохо» «А» сознательно не вводит (**решение**).
6. **Замена Excel/Word→PDF workflow** — косвенные (Gophish + LMS) его создают; прямые закрывают экспортом, но зрители CISO часто вне консоли → дашборд кормит доклад (актуальный срез), не обязан нести 3–6–12 на первом экране (**решение**).

## Паттерны, которые стоит взять
- Risk Score / Security Score (актуальный срез; тренд 6 мес. — опционально в отчётах, не must первого экрана) → `knowbe4.md`, `hoxhunt.md`
- CISO/Executive как отдельный артефакт (PDF/schedule), не toggle на странице → `knowbe4.md`, `proofpoint.md`, `solar-sa.md`
- Полный набор attack metrics + attachment/form → `phishman.md`, `gophish-evilgo.md` (детализация)
- CTA «на обучение» со сводки → `antiphish.md`
- Топ уязвимых / VAP → `proofpoint.md`; рейтинги подразделений без копирования traffic-light → `antiphish.md`
- HR learning-only срез → `corporate-lms.md` (референс метрик)

## Анти-паттерны
- Два режима ИБ/руководство на одной странице (оба интервью: нет) — не копировать «toggle persona».
- Подменять сводный дашборд разделом «Отчёты» (`00-product-a-input.md` — отдельная страница).
- Останавливаться на campaign results без org-сводки (`gophish-evilgo.md`).
- Строить ИБ-картину только из LMS completion (`corporate-lms.md`).
- Обязательная динамика 3–6–12 на первом экране — **не** требование «А» (**решение**); у KnowBe4 это опциональный референс для отчётов.
- Единый порог «плохо» / traffic-light по подразделениям — **не** требование «А» (**решение**).
