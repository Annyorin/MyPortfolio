## Белые пятна

1. **Один экран «индекс + атаки + обучение» без ухода в Отчёты** — у лидеров куски сильны (KnowBe4 Risk, Hoxhunt Score), у РФ часто жёсткая главная (Phishman) или слабо раскрыты виджеты (Solar, ASAP).
2. **Видимый путь «кликнул → назначили → завершил»** на сводке — элементы у KnowBe4 / Антифишинг / ASAP; в as-is интервью пути нет; Gophish+LMS рвут цикл.
3. **Связка графика: серия обучения (легенда) + список атак на вертикали** — **реш.** 2026-09-30 с техспециалистами; сложный hover TIP-A/когорта отменён. → `sources/decision-chart-index-2026-09-30.md`
4. **Срезы HR и SOC без dual-mode** — редко оба явно (KnowBe4 templates; Антифишинг→SIEM; LMS HR-only).
5. **ФИО-топ + отделы без светофора «плохо»** — VAP/рейтинги есть; порог «плохо» сознательно не копируем (**реш.**).

## Паттерны взять
- Risk / Security Score как якорь → KnowBe4, Hoxhunt.
- Attack metrics полный набор + attachment/form → Phishman, Gophish (детализация).
- Click vs report (+ miss, reporting time) → Hoxhunt.
- CTA «на обучение» со сводки → Антифишинг.
- Топ уязвимых / VAP как *идея списка*, не как реальный targeting → Proofpoint (не смешивать с учебным топом).
- Executive = файл/шаблон, не toggle на странице → KnowBe4, Proofpoint, Solar.
- HR learning-only срез → Corp. LMS / iSpring (статусы, балл, время, филиалы) — детали в `_matrix-attacks-reactions-training.md` §4.
- График: серия обучения (легенда) + список атак на вертикали → **реш.** 2026-09-30; не TIP-A/когорта в tooltip.

## Анти-паттерны
- Dual-mode ИБ/руководство на одной странице.
- Подмена сводки «Отчётами».
- Только campaign results без org-сводки → Gophish / EvilGo as-is.
- Картина ИБ только из LMS completion.
- Селектор горизонта 3–6–12 как must первого экрана (тренд в отчётах — ок).
- Traffic-light / единый порог «плохо» по подразделениям.
- VAP (реальные атаки) выдавать за учебный топ кликеров.
