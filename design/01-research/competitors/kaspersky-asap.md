# Kaspersky ASAP

## Позиционирование
Курсы + автоматические учебные фишинговые атаки + отдельные кампании проверки; библиотека шаблонов; результаты → корректировка обучения.

## Целевая аудитория
Организации на стеке Kaspersky; ИБ / awareness-админы.

## Ключевые сценарии
| # | Сценарий | Насколько хорошо закрыт (1–5) | Источник |
|---|----------|-------------------------------|----------|
| 1 | Автофишинг + курсы в одном продукте | 4 | k-asap.com / support |
| 2 | Результаты атак → корректировка обучения | 4 | raw |
| 3 | Единый risk-index dashboard (публично) | 2 | raw: «меньше деталей» |

## Дашборд / отчёты
- Публично меньше деталей про единый risk-index dashboard (уточнять при глубоком разборе). → `sources/competitors-sat-dashboard-raw.md`
- Известно: курсы, автоатаки, кампании проверки, шаблоны; результаты влияют на обучение. → [k-asap.com](https://www.k-asap.com/ru), [Support ASAP](https://support.kaspersky.com/ASAP/1.0/ru-RU/205085.htm)

## Сильные стороны
- Замкнутый цикл «атака → обучение» на уровне продукта.
- Автоматические учебные атаки снижают ручной ops.

## Слабые места / жалобы пользователей
- Слабая публичная прозрачность сводного дашборда / Risk Score — сложно бенчмаркать UX аналитики без доступа к продукту. → raw

## UX-паттерны, достойные внимания
1. Разделение автоматических учебных атак и кампаний проверки.
2. Корректировка обучения по результатам — паттерн связки, даже без детального UI дашборда в источниках.
