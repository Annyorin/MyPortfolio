# Solar Security Awareness

## Позиционирование
РФ SAT (РТК Солар): курсы + учебный фишинг + модуль аналитики/отчётов; AD/SSO; cloud / on-prem; экспертные отчёты для руководства о киберзащищённости персонала.

## Целевая аудитория
Корпоративный ИБ РФ; руководство (экспертные отчёты); on-prem сценарии.

## Ключевые сценарии
| # | Сценарий | Насколько хорошо закрыт (1–5) | Источник |
|---|----------|-------------------------------|----------|
| 1 | Курсы + учебный фишинг в одном сервисе | 4 | rt-solar.ru |
| 2 | Аналитика / отчёты для ИБ | 3–4 | raw (мало UI-деталей) |
| 3 | Экспертные отчёты для руководства | 4 | raw |
| 4 | On-prem + AD/SSO | 4 | on-premise page |

## Дашборд / отчёты
- Модуль аналитики/отчётов; экспертные отчёты для руководства о киберзащищённости персонала.
- Публично мало детализации виджетов первого экрана (Risk Score, open/click и т.д. не расписаны).
- → [Solar SA](https://rt-solar.ru/services/sa/), [On-premise](https://rt-solar.ru/services/sa/on-premise/)

## Сильные стороны
- Явный артефакт «отчёт для руководства» (совпадает с workflow PDF/доклада из интервью).
- On-prem — релевантно РФ enterprise.

## Слабые места / жалобы пользователей
- Слабая публичная детализация дашборд-паттернов (виджеты, метрики атаки, связка с обучением). → raw

## UX-паттерны, достойные внимания
1. Экспертный отчёт о киберзащищённости персонала как продуктовый deliverable.
2. Разделение cloud / on-prem без смены job (аналитика остаётся).
