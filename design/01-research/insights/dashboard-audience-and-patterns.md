# Insights: аудитория дашборда и паттерны

Короткие выводы фаз 0–2 + **решения человека** (2026-09-15). Факт/решение → источник; иначе *(гипотеза)*.

1. **Primary дашборда — операторы ИБ + зрители CISO/CTO/Директор ИБ**, не учащиеся. Соц. инженер и руководитель анализа готовят сводку; руководство потребляет результат. → `interview-ib-specialists.md`
2. **As-is = Excel / Word→PDF**, не «жизнь в платформе». Решение после цифр: доклад, назначить курсы, оценить эффективность обучения. Дашборд должен ускорять эти три исхода. → интервью
3. **Первый экран = последняя кампания / актуальный срез** (не окно 3–6–12). Обязательны метрики атаки: open / click / submit / report + вложение; у руководителя анализа ещё macro enabled. → интервью + **решение**
4. **Обучение на первом экране — статус потока:** сколько проходит / не закончили / завершили; не только «есть курсы». → интервью; LMS как референс completion
5. **Единый индекс (Risk Score) + пользователи по уровню риска + число кампаний / дата последней** — якорь для руководителя анализа. → интервью + `_matrix.md`
6. **Связка атака↔обучение** остаётся желаемой (Risk + факт обучения в актуальном срезе); путь «кликнул→назначили→завершил» as-is не виден. → интервью; белое пятно vs KnowBe4/Антифишинг/ASAP
7. **Топ уязвимых с ФИО — на сводке** (не только drill-down). Сравнение подразделений — болевые точки / типы атак **без** порога «плохо» / traffic-light. → интервью + **решение**; PII-constraint в brief
8. **V1 secondary:** HR — образование (обучение); SOC — уязвимые сотрудники и частые инциденты. Отдельные срезы, не toggle с ИБ/руководством. → **решение** (+ интервью)
9. **НЕ делать два режима «ИБ / руководство» на одной странице** — оба респондента: нет. Вместо этого: ИБ-сводка + экспорт/отчёт для зрителей. → интервью + конкуренты
10. **НЕ подменять дашборд разделом «Отчёты»** — отдельная страница сводки. → `00-product-a-input.md`
11. **Actionable summary** (назначить обучение со сводки) — сильный паттерн Антифишинг и JTBD соц. инженера. *(гипотеза приоритета UX)*
12. **Динамика 3–6–12 на первом экране не нужна** — рынок (KnowBe4 ~6 мес.) остаётся референсом для отчётов/drill-down, не must первого экрана «А». → **решение**
