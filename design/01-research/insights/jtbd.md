## Main job
**J1:** собрать и показать единую актуальную картину «обучение + атаки» (последняя кампания / текущий срез), достаточную для доклада, назначения курсов и оценки эффективности — без ручной склейки и без dual-mode на одной странице.

## Related jobs
- J2–J4 — исходы после сводки (доклад, назначить, оценить).
- J5–J6 — навигация по рискам людей/подразделений на сводке.
- J7 — потребление зрителями (экран или экспорт).
- J8–J9 — отдельные срезы secondary v1.

## Non-jobs
- Проходить курсы / тестирование как учащийся (кабинет учащегося). → `00-product-a-input.md`
- Переключать «режим ИБ / режим руководство» на одной странице. → интервью + решение
- Заменять раздел «Отчёты» сводным дашбордом. → input
- Строить обязательный тренд 3–6–12 на первом экране. → решение
- Полный редизайн Пользователи / Атаки / Шаблоны / Обучение / Учащийся. → scope research
- Вводить единый traffic-light порог «плохо» по подразделениям. → решение
