# Сырьё для исследования

Сюда клади всё без интерпретации: ссылки, цитаты, скрины, заметки.
Агент разложит по `briefs/`, `competitors/`, `insights/`.

Формат — в [`_shared/research/INPUT-FORMAT.md`](../../_shared/research/INPUT-FORMAT.md).

## Пример минимального ввода

```markdown
## Тема
[одно предложение]

## Зачем
[какое решение примете]

## Что уже знаете
- …

## Конкуренты
- …
```

Удали этот пример после первого реального исследования.
