# Avatar

## Назначение
Круглый аватар профиля 48×48.

## Анатомия
Изображение / заполнитель в круге.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 48×48 | единственный на витрине |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size | 48×48 fixed |

## Правила применения
Использовать с Profile в шапке сайдбара / профиля.

## Чем не является
Не Profile (Profile = аватар + текстовый блок).
