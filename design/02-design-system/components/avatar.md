# Avatar90

> Figma-имя мастера: **Avatar90**. Ранее в тексте DS фигурировал как Avatar 48×48.

## Назначение
Круглый аватар профиля; мастер **90×90**. В композициях может сжиматься (например ProfileMobile → 48×48).

## Анатомия
Изображение / заполнитель в круге.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 90×90 (мастер) | витрина / крупный профиль |
| instance @48 | 48×48 | ProfileMobile |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size (мастер) | 90×90 fixed |

## Правила применения
Использовать с **Profile** / **ProfileMobile**. Не плодить отдельный 48px-компонент — только instance scale.

## Чем не является
Не Profile / ProfileMobile (те = аватар + текст).
