# Chip

## Назначение
Компактный фильтр / тег высотой 32.

## Анатомия
Текст (Caption) в пилюле / контейнере h32.

## Варианты
| Вариант | node-id | Когда |
|---------|---------|-------|
| Property 1=default | `41:11648` | не выбран |
| Property 1=active | `41:11650` | выбран |

## Состояния
default / active

## Токены
| Свойство | Токен |
|----------|-------|
| height | 32 |
| text | Caption |
| fill active | Primary / White (по макету) |

## Правила применения
Навигация-фильтр, не кнопка действия (см. Tapper / Hover).

## Чем не является
Не Tapper, не Stiker, не Link.
