# CursorFigma

## Назначение
Иконка-маркер «Cursor / Figma» 20×20 для бейджей инструментов / стека.

## Анатомия
Один глиф 20×20 (SVG), без текста.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 20×20 | единственный |

## Состояния
default

## Токены
| Свойство | Токен / значение |
|----------|------------------|
| size | 20×20 fixed |

## Правила применения
Рядом с social-icons 20×20 (`behance`, `linkedin`, `mail`, `cv`, `telegram`). Не путать с **CursorHover** (CTA 114×40).

## Чем не является
Не CursorHover, не arrow-right 24×24.
