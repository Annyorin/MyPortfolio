# Link

## Назначение
Текстовая ссылка без кнопки-контейнера.

## Анатомия
Текст Text / H2 по контексту.

## Варианты
| Вариант | node-id | Когда |
|---------|---------|-------|
| Property 1=default | `41:11655` | покой |
| Property 1=hover | `41:11657` | наведение |

## Состояния
default / hover

## Токены
| Свойство | Токен |
|----------|-------|
| color default | Gray_text / Black |
| color hover | Primary (по макету) |

## Правила применения
Инлайн-навигация и текстовые переходы.

## Чем не является
Не Hover (кнопка «Behance»+arrow), не Chip.
