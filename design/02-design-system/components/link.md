# Link

## Назначение
Текстовая ссылка без кнопки-контейнера.

## Анатомия
Текст Text / H2 по контексту.

## Варианты
| Вариант | node-id | Когда |
|---------|---------|-------|
| Property 1=default | `40:1198` | покой |
| Property 1=hover | `40:1197` | наведение |

## Состояния
default / hover

## Токены
| Свойство | Токен |
|----------|-------|
| color default | Gray_text / Black |
| color hover | Primary (по макету) |

## Правила применения
Инлайн-навигация и текстовые переходы.

## Чем не является
Не CursorHover (кнопка «Behance»+arrow), не Chip, не Button.
