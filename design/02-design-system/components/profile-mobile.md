# ProfileMobile

## Назначение
Горизонтальный компактный профиль для мобильной / узкой зоны: аватар + имя + роль (240×48).

## Анатомия
| Слой | Описание |
|------|----------|
| Photo | instance **Avatar90** (`41:11499`), сжатый до **48×48** |
| Info | колонка: name (H1) + role (Text1 / GrayL) |
| Layout | row, `gap` **16**; Info `gap` **4**; ширина **240** |

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 240×48 | единственный |

## Состояния
default

## Токены
| Свойство | Токен / значение |
|----------|------------------|
| width | 240 |
| avatar size (instance) | 48×48 (мастер Avatar90 = 90×90) |
| name | H1 · Inter Semi Bold 20/24 · Black product `#232323` |
| role | Text1 · Inter Regular 16/20 · GrayL `#6B6B6B` |
| gap row / info | 16 / 4 |

## Правила применения
Мобильная шапка / узкий профиль. Десктопный блок — **Profile** (`40:1187`). Мастер аватара — **Avatar90**, не отдельный 48px-компонент.

## Чем не является
Не Profile (вертикальный / расширенный блок витрины). Не сырой Avatar90.
