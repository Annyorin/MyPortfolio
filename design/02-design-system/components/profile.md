# Profile

## Назначение
Блок профиля на витрине: аватар + текстовый стек (240×154).

## Анатомия
Avatar90 + текстовая колонка (имя / мета).

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 240×154 | единственный на витрине |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size | 240×154 |
| avatar | Avatar90 |

## Правила применения
Шапка Sidebar / блок «обо мне» на десктопе. Компактный горизонтальный вариант — **ProfileMobile** (`169:11933`).

## Чем не является
Не Avatar90, не ProfileMobile.
