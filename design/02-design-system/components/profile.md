# Profile

## Назначение
Горизонтальный блок профиля: аватар + имя / мета (240×48 на витрине).

## Анатомия
Avatar + текстовая колонка (H2 / Caption по смыслу).

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 240×48 | единственный |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| text | H2 / Caption |
| avatar | Avatar 48×48 |

## Правила применения
Шапка Sidebar / блок «обо мне».

## Чем не является
Не отдельный Avatar — Profile композиция.
