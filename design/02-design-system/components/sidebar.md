# Sidebar

## Назначение
Боковая панель профиля / навигации 310×561.

## Анатомия
Profile, Chip-фильтры, ссылки, CTA (Tapper / CursorHover / Button / Stiker) в колонке 310.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 310×561 | единственный на витрине |

## Состояния
default (+ внутренняя тень Shadow по ТЗ)

## Токены
| Свойство | Токен |
|----------|-------|
| size | 310×561 |
| shadow | Shadow `0 5px 9px #BBBBBD40` |
| fill | White / Secondary |

## Правила применения
Композиция атомов; не дублировать Card.

## Чем не является
Не Card.
