# Stiker

## Назначение
Стикер-бейдж 81×32 с копирайтом «Обо мне». Имя **Stiker** — орфография макета Figma (не Sticker).

## Анатомия
Контейнер + Caption «Обо мне».

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 81×32 | единственный |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size | 81×32 |
| text | Caption |

## Правила применения
Метка секции / профиля. Не путать с Chip (фильтр) и Tooltip.
На сцене Портфолио · Главная (`41:1416`) размер сверять по bbox сцены, не только atomic 81×32 витрины.

## Чем не является
Не Chip, не Tapper, не Tooltip.
