# Tapper

## Назначение
Кнопка-таппер 104×40 для основного действия на витрине.

## Анатомия
Контейнер + label.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 104×40 | единственный на витрине |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size | 104×40 |
| text | H2 / Text |

## Правила применения
CTA без стрелки / без social-icon. Со стрелкой Behance — CursorHover. С icon+label — **Button**. FAB — **FloatingAction**.

## Чем не является
Не CursorHover, не Chip, не Link, не Button, не FloatingAction.
