# Tapper

## Назначение
Кнопка-таппер 104×40 для основного действия на витрине.

## Анатомия
Контейнер + label.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | 104×40 | единственный на витрине |

## Состояния
default

## Токены
| Свойство | Токен |
|----------|-------|
| size | 104×40 |
| text | H2 / Text |

## Правила применения
CTA без стрелки. Со стрелкой — Hover.

## Чем не является
Не Hover, не Chip, не Link.
