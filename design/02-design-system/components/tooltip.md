# Tooltip

## Назначение
Короткая подсказка / лейбл поверх UI (витрина 66×36).

## Анатомия
Pill-контейнер (Black product, radius 25, padding 16×8) + текст H2 White.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| default | ~66×36 (по контенту) | единственный мастер |

## Состояния
default (на витрине также инстансы `92:11498`, `92:11500`)

## Токены
| Свойство | Токен / значение |
|----------|------------------|
| fill | Black product `#232323` |
| text | H2 · Inter Medium 16/20 · White `#FEFEFE` |
| radius | 25 |
| padding | 16×8 |

## Правила применения
Краткие подписи к контролам / зонам. Не заменяет Chip и не используется как кнопка.

## Чем не является
Не Chip, не Button, не Stiker.
