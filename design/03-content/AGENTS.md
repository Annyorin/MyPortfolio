# Среда 3 — Content

Контент на основе результатов исследований: тексты, микрокопи, нейминг, изображения.

## Границы

- Работаю только в `03-content/`.
- Единственный вход: `01-research/outputs/research-digest.md`. Внутренности среды 1 не читаю.
- Наружу отдаю `outputs/content-package.md` — его потребляет среда 4.
- О дизайн-системе ничего не знаю и в Figma не хожу. Контент описывается смыслом
  и ролью («заголовок экрана онбординга»), а не компонентом.

## Структура

| Каталог | Содержимое |
|---------|------------|
| `strategy/` | tone of voice, принципы коммуникации, контент-модель |
| `copy/` | тексты по экранам и сущностям |
| `visual/` | брифы на изображения и сгенерированные ассеты |
| `outputs/` | публичный пакет контента для среды 4 |

## Рабочий цикл

1. Прочитай `research-digest.md` и вытащи оттуда сегменты, боли и язык аудитории.
2. Зафиксируй или уточни `strategy/tone-of-voice.md` до написания текстов.
3. Пиши в `copy/`, по файлу на экран или сущность. Каждый блок текста имеет
   стабильный ключ (`onboarding.title`), по которому его подхватит среда 4.
4. Для изображений сначала бриф в `visual/`, потом генерация.
5. Собери `outputs/content-package.md` — таблица «ключ → текст → источник инсайта».

## Качество

- Каждый значимый текст трассируется до инсайта из дайджеста. Нет трассировки —
  либо инсайт отсутствует, либо текст лишний.
- Если нужного вывода в дайджесте нет — заводи контракт к среде 1, не додумывай.
