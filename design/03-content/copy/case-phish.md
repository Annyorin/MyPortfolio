## Слой A — факты

| Поле | Черновик |
|------|----------|
| Продукт | InnoPhish учит людей не вестись на фишинг. Кейс — сводный дашборд (обучение + атаки + реакции), не весь продукт. |
| Период / платформа | 2024–2026 · Desktop. |
| Роль | UX/UI: Discovery и ux-исследование для дашборда, макеты. |
| Команда | 4 фронтендера, 4 бэкендера, дизайнер, проджект-менеджер; стейкхолдеры CISO и директор ИБ. |
| Сцена «до» | Пробные рассылки и статистика вручную / EvilGo. Сводку для руководства клеили в Excel → Word/PDF. |
| Боль человека | Нет одного экрана «обучение + атаки». Нет ответа «насколько эффективно обучение». Нет готового файла для руководства. |
| Цена для бизнеса | Часы ИБ на статистику и обучение. Доверие заказчиков к эффекту курсов. Нет делегирования обучения в HR. |
| Критерии успеха | Меньше времени на сводку; аналитика одним файлом; курсы закрывают пробелы; делегирование в HR. |
| Результат | Страница дашборда в прод. После теста — три вкладки: Атаки / Реакции / Обучение. Среднее время сценария теста: 3,4–3,5 мин → 45 сек. |
| Доказательство | Коридор / модерируемый тест n=8. ~60% — кампания EvilGo до дашборда, не эффект UI. |
| Не стали | Dual-mode ИБ/руководство; подмена сводки «Отчётами»; картина только из EvilGo или только из LMS. |

JTBD (главная): когда нужно закрыть доклад по программе, хочу за один заход увидеть обучение и атаки в актуальном срезе, чтобы не собирать Excel/Word/PDF.

### Продукт (`context_title` / `context_body`)

Программа для повышения осведомлённости сотрудников в области ИБ и укрепления их устойчивости к кибератакам, основанным на социальной инженерии. Повышает общую защищённость организации от киберугроз.

В продукте есть рассылки учебных атак, аналитика атак, курсы и отчётность.

### Контекст + вводные блоки (`intro_title` / `intro_body`)

`intro_title` = Контекст задачи.

Тело: сцена Excel/Word → задача отдельной сводки → ## Цель / ## Аудитория / ## Проблема для пользователей / ## Проблема для бизнеса / ## Критерии успеха (канон Figma `509:18872`).
