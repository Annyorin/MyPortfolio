InnoPhish — скорость реакции на атаки

Отдельный блок вкладки «Атаки» на сводке: время до репорта (фидбэк «это фишинг») по учебным атакам. Список атак, не людей. Паттерн time-to-report. Это структура, не визуальный стиль. Рядом: сводка 3 вкладки · главная ИБ.

Медиана — главное число, среднее не показываем Min только внутри атаки / шаблона Репорт и клик — разные срезы Без лидерборда людей и общего рекорда ФИО не на сводке

Один блок, четыре ячейки. Срез «Репорт» — канон. «Клик» — второй срез, не в одной ячейке с репортом.

2. Невидимая логика

Правила, которых нет на каркасе, но их нельзя потерять между флоу и кодом.

  • Почему не среднее. Выбросы (очень поздний репорт) ломают среднее. В UI среднее не пишем. Репрезентативное число — медиана time-to-report.
  • Почему не общий min. Один рекорд «самая быстрая реакция по всем атакам» не даёт картины. Над списком — орг-медиана среза. Min живёт только в строке атаки / шаблона: потолок скорости и сложность обнаружения этого шаблона.
  • Не лидерборд людей. Не ранжируем сотрудников «самые быстрые по всем атакам». Единица списка — учебная атака (название · дата · тип шаблона).
  • Порог «мало событий». n < 3 репорта на атаку (и на орг-срез): медиану не считаем — «—» и чип «мало событий». Минимум можно показать уже с 1 события. 0 репортов — отдельное состояние IP-SPD-EMPTY, не SPARSE.
  • Знаменатель. n = люди с репортом (фидбэк «это фишинг»), не все delivered. В срезе «Клик» n = люди с кликом. Delivered можно подписать в EMPTY, чтобы не спутать с «нет кампаний».
  • Два сигнала, два среза. Репорт = определили атаку (хорошо быстрее). Клик = риск, если быстро (автопилот). Не класть оба числа в одну ячейку. Сегменты «Репорт» / «Клик».
  • Клик по строке ведёт в раздел Атаки (карточка / список этой кампании). Не в профиль человека.
  • Дрифт min между отделами. Минимум сильно плавает от отдела к отделу. Не строить ранжир подразделений по min. Сравнение шаблонов — по медиане репорта.
  • PII. ФИО рекордсменов на сводке нет. При необходимости — tooltip / drill в Пользователи, не первый экран.
