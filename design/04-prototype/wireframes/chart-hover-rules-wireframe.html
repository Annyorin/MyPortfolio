3. Класть / не класть

Класть
  • Имя атаки, дата, delivered
  • Click · Submit · Фидбэк (% + N)
  • Одна волна до атаки
  • Когорта F со знаменателями
  • Δ к предыдущей атаке (Should)
Не класть
  • Полный Гант / все курсы
  • ФИО людей
  • Формулу индекса
  • Статусы назначений
  • Open/Attachment, если тесно
  • Выдуманную когорту без данных
TIP-RULES
Нет даты «курс завершён до атаки» → слой 2 = одна фраза «нет данных по когорте», без 5% / 18%.

4. Desktop hover vs тач

Desktop
hover ● → карточка у точки → click → атака
Уход курсора скрывает карточку. Не перекрывать соседние точки.
TIP-DESK
Позиция: рядом с точкой, flip влево у правого края.
Тач / узкий экран
tap ● → sheet снизу → tap ✕ / фон
Не hover. Повторный tap по той же точке закрывает или оставляет закреплённым (один режим на продукт).
TIP-TOUCH
Тот же состав TIP-A, другая оболочка.

7. Программа vs курс vs волна — как подписывать

Иерархия в одной строке
Программа — один раз над списком ( Awareness / Phishing defense ), если все волны из неё.
Если волны из двух программ — не дублировать шапку: в каждой строке префикс программы коротким ярлыком.

Пример строк:
· Awareness / «Фишинг базовый» · волна 2 · с 1 авг
· Onboarding / «ОС логин» · с 5 июл
Не делать
  • Дерево программ целиком
  • «Все курсы программы Awareness (12)»
  • Смешивать в когорте нерелевантный курс (онбординг firewall к clickfix-ссылке) без домен-фильтра
  • Считать «с курсом», если курс начат после старта атаки

8. Определение «с курсом» при многих курсах

С курсом = человек завершил ≥1 релевантный курс/волну до даты старта атаки (в lookback).
Без курса = не завершил ни одного релевантного до якоря (включая «не начато» и «в процессе»).
Не в когорте = не получал эту атаку (не в delivered) — в знаменатель F не класть.
Lookback open Q: 90 / 180 дн. Дольше — шум «древних» курсов.
«Ещё N» в TIP-A2 ведёт на вкладку Обучение с фильтром периода до атаки — не раскрывает список в tooltip.

9. Сводка правил одной строкой

● атака → TIP-A / TIP-A2 (атака + до 2 волн + одна когорта) → клик в Атаки
│ волна → TIP-B (только эта волна) → Обучение
— линия / фон → ничего
N курсов → отбор по дате + домен + лимит 2; когорта = union «≥1 релевантный»
? нет данных когорты → заглушка без цифр F
📱 tap → sheet с тем же составом
