2. Логика и источники

  • Организация — имя тенанта на первом экране (не только бренд продукта «Программа А» в shell).
  • Индекс защищённости — org Risk / Security Score; выше = лучше. Формула — open Q (A3). Рядом — счётчики людей по уровням риска (US2 / KnowBe4 Group Report Card).
  • График — % click кампаний + маркеры атак + периоды обучения (Гант). Закрывает P3/O4; паттерн связки training↔phishing у KnowBe4/Hoxhunt.
  • Реакции: Open · Click · Attachment · Submit · Feedback/Report. Знаменатель = delivered. Feedback ≠ уязвимость.
  • Скорость: min и медиана time-to-report (Hoxhunt reporting time) + min/медиана time-to-click как риск-сигнал.
  • Последние атаки — учебные кампании; имена в стиле ЦИБ: техника + маска сервиса + цель (напр. «Кликфикс SSO Битрикс»). Не VAP / не SIEM.
  • Приоритет «кого учить» — после курса снова / без курса (из Реакций); CTA → DASH-ASSIGN.
  • Чипы Обучение / Реакции / SOC — срезы, не dual-mode. Экспорт — доклад, не подмена Отчётами.
