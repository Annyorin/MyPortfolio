3. Откуда улучшения (конкуренты + литература)

KnowBe4 — Phish-prone % / failures % и failures считаются от доставленных; в одном письме несколько failures (click + attachment). → у нас % + абсолют от 1 142; пересечения оговорены; уязвимые = уникальные.
support.knowbe4.com · Failures and Phish-prone Percentages
KnowBe4 / Canham — repeat clickers Повторные провалы (часто ≥3 симуляции) — малая доля людей, непропорциональный риск; remedial после курса. → приоритет «после курса» выше «не начато».
KnowBe4 blog · A Clicking Time Bomb; NIST/Canham differential susceptibility
Hoxhunt — click / report / miss Failure rate недостаточен; report и miss (ни клик, ни репорт) обязательны для картины human risk. → колонка Miss 71%.
Hoxhunt · Guide to Cybersecurity Training Metrics
Hoxhunt / KnowBe4 — связка training ↔ phishing PPP / risk рядом с completion; эффект программы виден в динамике. → блок «хвост после атаки» + когорта 5% vs 18%.
KnowBe4 reporting (PPP by training); Hoxhunt Human Risk Dashboard
Proofpoint — VAP ≠ simulation fail Very Attacked People = реальный targeting. Не смешивать с учебным топом уязвимых. → явная подпись «учебные реакции»; VAP только при интеграции.

4. Логика вне каркаса

  • Знаменатель метрик атаки — всегда delivered (и подпись). Не open-rate base для click, если не переключили явно.
  • Уязвимый — уникальный человек с ≥1 из {click, attachment, submit} в срезе. Report сам по себе не делает уязвимым.
  • Приоритет топа: (1) завершено/провалено курса + опасная реакция, (2) в процессе + реакция, (3) не начато + реакция. Внутри — тяжесть submit > attachment > click, затем число кампаний.
  • Индекс защищённости — выше лучше; на каркасе показан тренд. Формула — open Q (A3); не путать ось с click% (выше хуже).
  • Miss — 100% − (доля с click∪report) приближённо; точная формула Hoxhunt — за окно N дней после доставки.
  • Когорта — только люди, получившие эту кампанию; «с курсом» = завершили релевантный курс до даты старта кампании.
  • Не вливать слепо в DB-IB-D без выбора: высота экрана, обязателен ли Miss на первом экране, когорта на primary или в развороте кампании.
