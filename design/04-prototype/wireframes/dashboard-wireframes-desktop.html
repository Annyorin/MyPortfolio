Программа А — сводный дашборд — desktop вайрфреймы

Desktop lo-fi каркасы сводной аналитики InnoPhish / программа «А»: shell, primary ИБ с графиком индекса (реш. 2026-09-30), срезы HR/SOC, empty/loading, modal назначения, TIP-VERT (список атак на вертикали). Паттерны: Risk + атаки + обучение | топ ФИО, подразделения без traffic-light. Детали графика: risk-index-chart · hover rules · home: dashboard-ib-home. Mobile: dashboard-wireframes.html. Это структура, не визуальный стиль.

Первый экран = последняя кампания / актуальный срез Нет dual-mode ИБ/руководство Дашборд ≠ Отчёты HR = обучение · SOC = уязвимые + инциденты График: индекс + серия обучения · вертикаль → TIP-VERT Нет TIP-A / когорты в tooltip

Логика, которую не видно на каркасах

Desktop vs mobile: та же IA; на desktop — боковой shell и колонки. Данные первого экрана: последняя кампания / org-срез — без UI 3–6–12. График (2026-09-30): индекс + серия обучения (toggle легенды); вертикаль → TIP-VERT (список начавшихся атак); TIP-A/когорта — отказ. Метрика серии «обучение»: completion% / активные волны — уточнить с техспециалистами (дыра IA §6.7). Подразделения: без traffic-light и порога «плохо». PII: ФИО топа по ролям; иначе маскирование (A2). Экспорт: one-shot среза; архив — Отчёты. Срезы: HR без Risk/атак; SOC ≠ SIEM. ASSIGN: desktop modal (не bottom sheet). Кабинет учащегося: вне графа дашборда.
