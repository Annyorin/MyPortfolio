Программа А — сводный дашборд — desktop вайрфреймы

Desktop lo-fi каркасы сводной аналитики (обучение + атаки): shell-навигация разделов, многоколоночный layout primary ИБ, срезы HR/SOC, empty/loading, modal назначения и drill в Атаки. Паттерны: Risk + attack metrics в ряд, обучение | топ ФИО, подразделения без traffic-light. Mobile-доска: dashboard-wireframes.html. Это структура, не визуальный стиль.

Первый экран = последняя кампания / актуальный срез Нет dual-mode ИБ/руководство Дашборд ≠ Отчёты HR = обучение · SOC = уязвимые + инциденты ФИО топа на сводке · без порога «плохо» Desktop: shell слева · контент в колонках

Логика, которую не видно на каркасах

Desktop vs mobile: та же IA; на desktop — боковой shell и колонки вместо вертикального стека. Данные первого экрана: последняя кампания и/или org-актуальный срез — без UI тренда 3–6–12. Подразделения: таблица болевых точек и типов; запрещены traffic-light и единый порог «плохо». PII: ФИО топа только ролям с доступом; иначе маскирование / агрегат (A2). Экспорт: one-shot актуального среза в header; schedule/архив — через Отчёты. Срезы: HR не тащит Risk/атаки; SOC не заменяет SIEM. ASSIGN: на desktop — modal по центру (не bottom sheet). Кабинет учащегося: в shell дашборда не показываем как цель.
