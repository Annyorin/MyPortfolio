InnoDragon — настройки уведомлений — desktop вайрфреймы

Каркасы куска «уведомления»: лента → настройки как таблица событие × канал (Monday / Weeek), не вкладки KSC. Колонки: Системные · Почта · Telegram. Подключение канала отдельно от галочек. Это структура, не визуальный стиль.

Матрица: строка = событие, колонка = канал Канал ≠ вкладка с копией дерева Connect бота / SMTP отдельно Группа с чекбоксом по колонке Одно сохранение политики
1 Политика за один заход
2 Канал не подключён
3 Массовое выкл + Undo
4 Ошибка / пусто
Вход: shell → Уведомления → Лента → Настройки событие × Сист / Почта / TG → Выход: Save · Connect · Undo

Лента → настройки. Одна таблица: события слева, каналы колонками. Статус канала над таблицей. Cancel / Save справа.

NTF-9. Выровнять по колонке
Замена «Применить ко всем вкладкам»: копирование одной колонки в другие. Не в неподключённый TG.

Логика, которой нет на каркасах

Правила поведения — чтобы не потерять между флоу и UI.

  • Нет вкладок каналов: одна матрица, как Monday (событие × Bell/Email/Mobile) и Weeek (форматы на событии).
  • Ячейка = пересечение события и канала. Групповой чекбокс слева управляет строкой; чекбокс в шапке колонки — всеми событиями канала.
  • Минус в ячейке группы×канал → клик всегда «вкл колонку для группы». Выкл — из галочки.
  • Неподключённый канал: колонка disabled + Connect в шапке. Не молчаливый save.
  • «Выровнять по колонке» — опция; Save — единственная фиксация на сервер.
  • Отчёт об инцидентах — строка внутри группы «Инцидент». Группа «Сканирование» — не глагол.
