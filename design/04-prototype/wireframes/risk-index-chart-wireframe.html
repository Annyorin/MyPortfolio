1b. Рекомендация v1 — линия + лёгкие метки обучения (без Ганта)

CHART-TIP. Ховер точки атаки
Слой 1 — атака (имя ЦИБ, дата, delivered, 3 метрики). Слой 2 — обучение к ней (волна + когорта F). Без списка курсов и без Ганта.

Правила ховера

  • Триггер: ● учебной атаки. Ховер на «пустой» линии или только на вертикали волны — другая подсказка (см. ниже) или ничего.
  • Слой Атака (всегда): название в стиле ЦИБ; дата старта; доставлено; Click + Submit + Фидбэк (Open — optional, чтобы не раздувать). % и абсолют.
  • Слой Обучение (если метки вкл.): одна строка «ближайшая волна до этой атаки» (имя + дата старта / «за N нед.»). Затем когорта F: click% с курсом vs без — знаменатели обязательны.
  • Не в ховере: полный Гант; все курсы org; ФИО; статусы назначений; формула индекса; сравнение с предыдущей кампанией длинным текстом (достаточно Δ click в одной строке, если есть).
  • Δ к предыдущей атаке (Should): одна строка «click −7 п.п. к 28 авг» — дешёво и полезно для доклада.
  • Клик: по карточке / кнопке «Открыть» → EXT-ATTACKS. Вторичная ссылка «Люди когорты» → список с фильтром (с курсом / без) — не в v1 must.
  • Ховер на │ старт волны (не точка атаки): короче — только «Волна „Фишинг“ · апр–май · N назначено». Без когорты F (нет кампании-якоря).
  • Пусто / дыра данных: если нет даты завершения курса — блок когорты: «Нет данных, кто завершил курс до атаки» + только слой атаки. Не рисовать 5% / 18%.
  • Mobile / тач: тап по точке закрепляет карточку снизу графика (sheet), повторный тап / «✕» закрывает. Не полагаться на hover.

Число Risk Score остаётся якорем «сейчас». График — аргумент «курсы сработали / забыли». На первом экране можно зона-Гант; полный Гант с рядами курсов — в развороте или на вкладке тренда.

Логика, которой нет на каркасе

  • Метрика линии (выбор): % click / fail учебной атаки — прямо отвечает на «часто попадаются». Альтернатива — Risk Score во времени; тогда ось «выше = лучше» и подпись меняется.
  • Гант: ряд = тип курса или волна назначения. Статусы: активно / завершено / назначен без прохождения (пунктир).
  • Симуляции — маркеры на оси или отдельный трек «Атаки», иначе не видно проверку после курса.
  • Ещё варианты атак+обучение (не внедрены в primary): C столбцы; D Risk-линия; E completion-линия; F когорта — в ховере точки (CHART-TIP), не отдельным виджетом на первом экране.
  • Ховер точки атаки: имя + метрики → до 2 релевантных волн → одна когорта (union ≥1 курс до атаки). Не по когорте на каждый курс. Гант в tooltip не тащить.
  • Не делать: светофор «плохо» по подразделениям на этом виджете; dual-mode ИБ/руководство; подмену графика разделом «Отчёты»; смешивать «выше лучше» и «выше хуже» без явной подписи оси.
  • Открыто: формула Risk Score (A3); дефолт линии click% vs Risk; полный Гант на первом экране или только в развороте; брать ли C или F в доклад CISO.
