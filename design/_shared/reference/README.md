# Справочные материалы

Внешние материалы для человека: конспекты, инструкции по установке, разборы чужих
пайплайнов. Агентами **не читаются по умолчанию** — только по прямой просьбе
пользователя и точечно, нужным фрагментом.

Причина: файлы объёмные и описывают окружение вне этой метасреды. Их попадание
в контекст рабочей задачи — трата бюджета внимания без пользы.

| Файл | Что это | Когда открывать |
|------|---------|-----------------|
| `ai-design-system-workflow.md` | конспект эфира: установка Claude Code, Figma MCP, сборка пайплайна DS от референса до Storybook | при настройке окружения с нуля или как источник идей для новых скиллов |
| `handout-documentation-system.md` | универсальные стандарты написания документации (принципы, метаданные, сжатие) | при выработке стиля доков или онбординге человека |
| `handout-documentation-rules.md` | конспект правил поддержки доков; рабочая версия — `.cursor/rules/60-doc-standards.mdc` | для сравнения с адаптированным правилом метасреды |

Материал отсюда не является правилом метасреды. Если из него нужно взять практику —
она переносится в скилл или в `AGENTS.md` среды, а не цитируется из справки.
