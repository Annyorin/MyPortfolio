## Компоненты

Список из `05-code/components/` vs Component Set на странице библиотеки в Figma.

| Компонент | Имя 1:1 | Variant props = React props | Значения вариантов | Статус | Комментарий |
|-----------|---------|----------------------------|-------------------|--------|-------------|
| | | ✅ / ❌ | ✅ / ❌ | ✅ / ⚠️ / ❌ | |

Проверять:
- имя компонента совпадает (`Button`, не `button-primary`);
- имена свойств вариантов = имена пропов в React;
- набор значений вариантов совпадает (например `primary | secondary | ghost`).
