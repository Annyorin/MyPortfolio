# Каталог: ds-showcase/

## Назначение
Статическая HTML+CSS витрина дизайн-системы (Ui kit). Без фреймворков и бандлера.

## Файлы

### README.md
Инструкция поставки: назначение витрины, открытие (`file://` / static server), стек HTML+CSS без сборки, ссылка Figma Ui kit `41:11646`, путь к evidence `docs/implementation/figma-ui-kit-reference.png`, запреты (`design/**`, якоря out of scope), Inter CDN.

### index.html
Точка входа. Подключает `css/tokens.css` → `css/components.css` → `css/showcase.css`.
`<main class="ds-showcase">` с `h1` (sr-only) и секциями IA: Foundations → Icons → Atomic → Composite → Media.
Демо-тексты — литералы по `design/03-content/outputs/content-package.md`.
A11y: `section` + заголовки; `alt` у медиа; `aria-label` у Icons / Tapper / Hover / Contacts.

### css/tokens.css
Канонические `:root` custom properties (ТЗ §3.1 / architecture §4.2): ColorToken (+ GrayL), `--shadow`, TypographyStyle, `--page-bg: var(--color-white)`.
`@import` Inter 400/500/600 (Google Fonts CDN); A1 fallback `sans-serif` на `body` в `showcase.css`.

### css/components.css
Icons + Atomic + Composite: Avatar90, Profile, ProfileMobile (`--mobile` 240×48), Chip, Link, Button, Tooltip, Tapper, Stiker, Hover/CursorHover, FloatingAction (`.ds-fab` 50×50); Card 310×310; Sidebar 310×561.
Icons включают CursorFigma 20×20. Размеры по screen-spec / Figma (±2px); fill через `var(--color-*)`.

### css/showcase.css
Page shell: вертикальный flex-поток секций, светлый `var(--page-bg)`, Inter + sans-serif.
`@media (min-width: 1280px)` — `overflow-x: hidden` у shell/секций; узкие — wrap + composite column stack.
Foundations: `.ds-swatch` 80×80 через `var(--color-*)` (7 шт., без GrayL) + type specimens `.ds-type--*` на `var(--type-*-*)`.
`.ds-media` / `.ds-placeholder` (+ `.ds-avatar.ds-placeholder`) — A2 пропорции при битом `src`; Media slots: IMG_*, Comp, me, Macbook, SityBike 308×190.

### assets/icons/
SVG: close, plus, minus, arrow-right, social, cursor-figma (экспорт из Figma Ui kit `41:11520`).

### assets/images/
Растр: avatar, card-citybike (Card + SityBike cover), img-bg, img-1, img-2, img-3, comp, me, macbook.
См. `assets/.AGENTS.md` (MediaAsset ↔ путь).

### assets/fonts/
Опционально локальный Inter (пока пустой, `.gitkeep`; CDN Inter в tokens.css).

## Зависимости
- Нет runtime-зависимостей (кроме CDN Inter при онлайн-просмотре)
- Спеки handoff: только чтение `design/**/outputs/` и `docs/implementation/`
