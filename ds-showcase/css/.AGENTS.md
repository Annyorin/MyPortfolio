# Каталог: ds-showcase/css/

## Назначение
CSS-слои витрины: токены, компоненты, layout страницы.

## Файлы

### tokens.css
Канонические custom properties в `:root` (ТЗ §3.1 / architecture §4.2):
- ColorToken: `--color-primary|secondary|white|black|gray-text|gray-dark|gray-l` (Black `#232323`; GrayL без свотча)
- ElevationToken: `--shadow` (`0 5px 9px #bbbbbd40`); эффект «вв» не объявляется
- TypographyStyle: `--type-{h1|h2|text|caption}-{size|line|weight}` (Inter)
- Page: `--page-bg: var(--color-white)` (светлая тема)
Font Delivery: `@import` Inter `wght@400;500;600` с Google Fonts CDN; A1 fallback `sans-serif` на `body` в `showcase.css`.

### components.css
Классы UI: Icons (24×24; Burger_menu; arrow-left/right; CursorFigma 20×20), Avatar90 (90 круг), Profile (240 column), ProfileMobile (`--mobile` 240×48 row, Avatar@48), Chip default/active h32, Link default/hover + `:hover` + `:focus-visible`, Button primary/secondary/text (+ Text hover Gray_text), Tooltip, Hint (`.ds-hint` white tip radius 0 25 25 25 + `--shadow`), Tapper 104×40 + эффект «вв» (не для Card) + `:focus-visible`, Stiker 81×32 + `var(--shadow)`, Hover CTA / CursorHover 114×40 (`.ds-hover--view` max-content для «Посмотреть») + white arrow mask + `:focus-visible`, FloatingAction (`.ds-fab` 50×50, shadow 0 5 / 4.5, arrow −90°), Header 620×81 py16 (text button + title flex), SegmentsControl 620 (pill active + shadow), TitleSidebar default/hover, SideNav TOC 262, Card 310×310 (default/hover = `var(--shadow)` + `:hover`), Sidebar 310×561 (Secondary border + Shadow; Skills gap 8; Contacts Caption + `:focus-visible`). Цвета через `var(--color-*)`.

### showcase.css
Page shell: вертикальный flex-поток `.ds-section`, фон `var(--page-bg)`, Inter; sr-only `.ds-showcase__title`.
`min-width: 1280px` — без критичного `overflow-x` секций; `max-width: 1279px` — wrap samples + composite column.
Foundations Catalog: `.ds-swatch` 80×80 с `background-color: var(--color-*)` (Primary…White; GrayL без свотча), подписи + hex; `.ds-type--h1|h2|text|caption` → `var(--type-*-*)`.
Composite: отступы Card-samples / Sidebar.
Media: целевые box IMG_BG/1/2 345×230, IMG_3 345×345, Comp ~149×103, me 254, Macbook 388×283, SityBike/Dragon/Phish 308×190, stickers; `.ds-placeholder` / `.ds-avatar.ds-placeholder` для A2.

## Зависимости
- Подключаются из `index.html` без бандлера
- Inter CDN (HTTPS) при наличии сети; fallback `sans-serif` в `showcase.css`
