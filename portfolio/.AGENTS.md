# Каталог: portfolio/

## Назначение
Сайт «Портфолио.Главная»: viewport + world-камера поверх Shared DS (`ds-showcase/`).

## Файлы

### README.md
Локальный запуск Главной (`npm run portfolio:dev` / `portfolio:static`), alias `@ds-assets`, эталон Figma `41:1416`; полный контракт поставки — корневой `README.md`.

### main.html
Каноническая оболочка «Портфолио.Главная»: `.viewport` → `#camera-pan` → `#world.world` + `#mobile-sheet` (document/mobile host); `<link>` на `../ds-showcase/css/tokens.css`, `../ds-showcase/css/components.css`, `css/portfolio.css`; модуль `js/main.js`.

### boot-demo.html
Standalone preview of reverse particle boot (loading → burst → gridSettle → cardsReveal → done): full-viewport canvas host, HUD (Restart / stage / progress / status), mock cards; module `js/bootDemo.js`. Open via `npm run portfolio:boot-demo`.

### case-dragon.html
Страница кейса InnoDragon (Figma breakpoints 1920 / 1366 / 1024 / 768 / 360): document-scroll, трёхколоночный layout, DS Header / SideNav / Segments / FAB / contacts; mobile toolbar + drawer backdrop (≤480); `data-case-id="dragon"`; модуль `js/case.js`, стили `css/case.css`.

### case-phish.html
Страница кейса InnoPhish (сводный дашборд): та же оболочка, что `case-dragon.html`; `data-case-id="phish"`; hero inline `images/phish.png`, lightbox hi-res `images/case-phish-hero-full.png` (`data-full-src` / `AssetRef.fullPathFromDsRoot`); нав: context / analysis / design / ux_test / finals / conclusions (без пункта «Контакты»). Тексты и img-markers — `case.phish.*` в `shared/content.js` (канон `copy/case-phish.md`, макет Figma `509:18872`). Lightbox + cursor zoom-in на `[data-case-zoomable]`.

### index.html
Редирект на `main.html` (совместимость старых ссылок).

### css/portfolio.css
Chrome viewport/world/camera + helpers слотов сцены (`.scene-node`, `.scene-bg`, `.scene-comp`, `.scene-tapper__hit`) без токенов DS; `.ds-placeholder` / `.ds-media-slot--broken` — геометрия media-слотов до load и при битом src; About Macbook stickers (%, hover drop-shadow + Hint); `.portfolio--mobile` — document-scroll layout `<1024` (Портфолио.768: cards 500 / body 104 / desc 32; `<768`→360 card height lerp 500→322, media flex-fill); ProfileMobile (role в одну строку).

### css/case.css
Только layout страницы кейса: default 1366 (sidebar sticky, main 668/620), ≥1920 (487/946/898), ≤1024 (без sidebar/gutter), ≤768 (padding 16), ≤480 (toolbar, drawer, contacts 2×2, hide next/FAB); inline pictures + Notion-like lightbox (close `ds-button-round--outlined` Figma `514:19567`: White/page-bg/Shadow + mask `close.svg` / `--color-gray-text`; dark через DS-токены; tapper `ds-tapper`, Escape / overlay) / zoom cursor для `[data-case-zoomable]`; без дублирования DS-токенов.

### js/main.js
- `initPortfolioStubs()` — режим по ширине: `<1024` → `mountMobilePortfolio` (класс `portfolio--mobile`, без камеры); `≥1024` → mountScene → createCamera → stage-fit / fitToContent → bindInput → bindInteractions; resize remount/teardown между mobile↔canvas; возвращает `{ camera, worldEl, viewportEl, scene, inputMode, layoutId, mode }`

### js/bootLoader.js
- `mountBootLoader` / `runPortfolioBoot` — portfolio boot stages with camera-aligned grid (`buildAlignedGridCells` + `INFINITE_BG`)

### js/bootDemo.js
- `mountBootDemo(rootEl, options)` — demo controller: uniform grid (`buildUniformGrid`), simulated progress, mock-card occluders, restart/destroy; reuses `boot/config|easing|ringLayout|gridLayout`
- `collectMockCardOccluders(root)` — rects from `[data-mock-card]`

### js/boot/
- `config.js` — `BOOT_CONFIG` timings/colors
- `easing.js` — easeOutQuad/Cubic/Back, pulseFunction
- `ringLayout.js` — `buildRingParticles`, `waveHeat`
- `gridLayout.js` — `buildUniformGrid`, `buildAlignedGridCells`, `assignNearestCells`

### js/mobile.js
- `mountMobilePortfolio(rootEl, content, resolveAsset, options?)` → teardown — Compact Sidebar (ProfileMobile 48, 4 кнопки Telegram/CV/Behance/Mail), 3 full-width cards (`buildCard`); без FAB

### js/case.js
- `initCasePage()` — читает `body[data-case-id]` (`dragon` | `phish`), prefix `case.${id}.`, card `card.a` / `card.b`; role/team из `role_value`/`team_value` (bio fallback); stub-секции + rich `[[img:]]` pictures + `[[jtbd:]]` grid (`contentMap.jtbdGrids`, Fill_Block compact); short/long через `bindSegmentsControl` + `[data-case-long-only]`; FAB / side-nav / drawer
- `setupCaseReveal()` — scroll fade-up по блокам (intro / context picture|fill|text / stub `> text-block|picture` / footer); ждёт layout картинок (`waitForCasePictureLayout`) + page-enter crossfade
- `setupCaseLightbox()` — Notion-like zoom: `[data-case-zoomable]`, prefers `img[data-full-src]` (hi-res) over inline `src`, close (`ds-button-round--outlined`), tapper (`ds-tapper` ±), Escape / overlay
- `CASE_FAB_SHOW_SCROLL_Y` / `CASE_FAB_DIR_SLOP_PX` — FAB виден только при scroll-up (скрыт при scroll-down и у верха)

### js/camera.js
- `createCameraController(worldEl, options)` — CameraController (§5.2): state `scale`/`translateX`/`translateY`; options `getViewportSize`, `getContentAABB`, `minScale=0.25`, `maxScale=4`, `zoomStep≈0.1`
- `screenToWorld` / `worldToScreen` — формулы §5.2
- `zoomBy(deltaStep, pivot)` — pivot `viewportCenter` | `{x,y}`; soft clamp; no-op на min/max
- `zoomTo(scale, pivotMode)` — `keepWorldCenter` для 100%
- `fitToContent(padding=24)` — вписать AABB, центр → центр viewport
- `panBy(dx, dy)` — screen delta + soft clamp (expand AABB на 1×viewport)
- `apply()` — при `scaleEl` + CSS `zoom`: pan-host `translate`, world `zoom`; иначе `translate(...) scale(...)` (без left/top детей)
- `getState()` — копия `{ scale, translateX, translateY }`

### js/scene.js
- `mountScene(worldEl, layout, content, resolveAsset)` → `{ nodesById, contentAABB }` — world DOM один раз: BG, Sidebar, Card×3, Comp, Stiker, Tapper (`ds-*` + layout geometry, paint order по zIndex)
- `buildCard(content, resolveAsset, imageAssetKey?, nodeId?)` — разметка Card (экспорт для mobile sheet); cardA/B — CursorHover «Посмотреть» (`.ds-hover--view`); cardC — CursorHover «Behance» 114×40 (Figma 260:24098)
- About Macbook: first paint flat `macbook.png` (Figma MacbookPng 391:22958), then soft crossfade to layered `macbook.lid` + `.scene-about__sticker` (PNG) + `.ds-hint`; stickers interactive only when `.is-about-open`
- Media-слоты (avatar / card media / comp): явная min-height/aspect + `data-media-slot`; Tapper/contacts — focusable controls (`button` / `a[href="#"]` + `tabIndex`)

### js/input.js
- `bindInput(viewportEl, camera, inputMode)` — Figma-like жесты → команды камеры (без rebuild сцены)
  - hotkeys: `+`/`−`, Ctrl|Meta+`=`/`+`/`−`/`0`, Shift+`0` → 100%, Shift+`1` → `fitToContent(24)`; Shift+2 вне scope
  - bare `+`/`−` игнор при фокусе в input/textarea/contenteditable
  - Ctrl|Meta+wheel → `zoomBy` к курсору; wheel → `panBy`; оба с `preventDefault` (`passive: false`)
  - Space+drag: `spaceDown` / `isPanning` / `suppressClicks`, курсор grab→grabbing
  - optional: middle-button drag и pan по BG / пустой области

### js/interactions.js
- `bindInteractions(worldEl, camera, inputMode)` → `unbind` — Tapper ± → `zoomBy(±zoomStep, viewportCenter)`; contacts `preventDefault` (без внешней навигации); при `inputMode.suppressClicks` capture-игнор click/pointerdown на Card/Link/Contacts; `error` на критичных img (avatar/card/comp) → `onImageError`
- `activateCardHit(card, event?)` — modal no-op / URL → `window.open` (общий хелпер canvas + mobile)
- Card CursorHover: pointermove → body `.ds-card__cursor-hover--float` (clone) + `translate3d(client+CARD_HOVER_OFFSET_PX)`; gap constant under camera zoom; drag скрывает
- `onImageError(eventOrImg)` — класс `ds-media-slot--broken` + min-size/aspect слота; `console.warn`/`console.error`; не бросает

### js/resolveAsset.js
- `resolveAsset(key, options?)` — читает `contentMap.assets[key].pathFromDsRoot`; URL = `@ds-assets/…` (Vite/Storybook) или `ds-showcase/assets/…` (static/repo); неизвестный key — `console.warn` + безопасный fallback без throw
