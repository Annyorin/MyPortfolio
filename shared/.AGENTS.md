# Каталог: shared/

## Назначение
Общие клиентские данные сцены: Content Map и Scene Layout Config для Portfolio и Storybook.

## Файлы

### content.js
- `contentMap` — полный словарь ключей content-package (§4.1): `profile.*`, `sidebar.bio`, `chip.*`, `contact.*` (только подписи), `link.sample`, `stiker.label`, `hover.label` / `hover.label.view`, `card.*` (вкл. `card.a.url`, `card.b.url` → case pages, `card.c.hover.label`), `case.dragon.*` / `case.phish.*`, `tapper.*`, `foundations.swatch_labels`, `typography.labels`
- `contentMap.chipVariants` — Sidebar skills: b2b/b2c `active`, design_system/ai_prototyping `default`
- `contentMap.assets` — AssetRef с `pathFromDsRoot` (avatar, card.image, img_*, comp, icons.*)
- Без entry-relative `../ds-showcase/...` путей

### layout.js
- `sceneGraph` / `nodes` — SceneNode слоты `41:1416` с `zIndex` (BG→Sidebar→Card×3→About→Tapper)
- `layout1024` / `layout1366` — артборды Figma
- `MOBILE_BREAKPOINT` (1024), `isMobileViewport(viewport)` — document/mobile mode (`<1024`, макет Портфолио.768)
- `selectSceneLayout(viewport)` — `<1024` → `null`; `≥1024` → `51:4107`
- `computeContentAABB(nodes)` — union bbox ключевого контента (card+about)
- `FIXED_CHROME_KINDS`, `STAGE_CHROME`, `interactiveStageRect`

## Зависимости
- Потребители: `portfolio/js/*`, `stories/*`
- Ассеты на диске: `ds-showcase/assets/` (резолв через `resolveAsset`, не из shared)
