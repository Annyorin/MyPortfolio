# Каталог: shared/

## Назначение
Общие клиентские данные сцены: Content Map и Scene Layout Config для Portfolio и Storybook.

## Файлы

### content.js
- `contentMap` — полный словарь ключей content-package (§4.1): `profile.*`, `sidebar.bio`, `chip.*`, `contact.*` (только подписи), `link.sample`, `stiker.label`, `hover.label`, `card.*`, `tapper.*`, `foundations.swatch_labels`, `typography.labels`
- `contentMap.chipVariants` — Sidebar skills: b2b/b2c `active`, design_system/ai_prototyping `default`
- `contentMap.assets` — AssetRef с `pathFromDsRoot` (avatar, card.image, img_*, comp, icons.*)
- Без entry-relative `../ds-showcase/...` путей

### layout.js
- `sceneGraph` / `nodes` — 8 SceneNode слотов `41:1416` с `zIndex` (BG→Sidebar→Card×3→Comp→Stiker→Tapper)
- `computeContentAABB(nodes)` — union bbox ключевого контента + расширение BG

## Зависимости
- Потребители: `portfolio/js/*`, `stories/*`
- Ассеты на диске: `ds-showcase/assets/` (резолв через `resolveAsset`, не из shared)
