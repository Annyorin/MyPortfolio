# Каталог: stories/

## Назначение
Storybook CSF-каталог инвентаря DS (UC-01): полные stories по витрине `ds-showcase`, тексты из `shared/content.js`, ассеты через `resolveAsset` / `@ds-assets`.

## Файлы

### Chip.stories.js
- `Default` — `ds-chip--default` (`chip.sample.default`)
- `Active` — `ds-chip--active` (`chip.sample.active`)

### Link.stories.js
- `Default` — `ds-link--default`
- `Hover` — `ds-link--hover`
- `Focus` — default link + focus after mount

### Card.stories.js
- `Default` — `ds-card--default`
- `Hover` — `ds-card--hover`
- Контент: `card.title` / `card.meta` / `card.description`, media `card.image`

### Sidebar.stories.js
- `Default` — profile, bio, skills (chipVariants), contacts

### Tapper.stories.js
- `Default` — − / + icons (`icons.minus` / `icons.plus`)

### Stiker.stories.js
- `Default` — `stiker.label`

### Hover.stories.js
- `Default` — CTA label + `icons.arrow-right`

### Avatar.stories.js / Profile.stories.js / ProfileMobile.stories.js
- `Default` — avatar asset + profile strings (ProfileMobile: `--mobile` 240×48)

### Button.stories.js
- `Primary` / `Secondary` / `Text` / `TextHover` — primary/secondary/text (+ static hover Gray_text)

### Header.stories.js
- `Default` — text button «На главную» + `header.title`

### Segments.stories.js
- `Long` / `Short` — SegmentsControl active pill

### TitleSidebar.stories.js
- `Default` / `Hover` — H2 black / Gray_text

### SideNav.stories.js
- `Default` — SideBar TOC list

### FloatingAction.stories.js
- `Default` — `.ds-fab` 50×50

### CursorFigma.stories.js
- `Default` — 20×20 cursor icon

### Icons.stories.js
- `Default` — close, Plus, Minus, Burger_menu, arrow-right, arrow-left

### Media.stories.js
- `Default` — IMG_BG, IMG_1, IMG_2, IMG_3, Comp (+ me, Macbook)

## Зависимости
- `.storybook/` (preview импортирует `ds-showcase/css`)
- `shared/content.js`
- `portfolio/js/resolveAsset.js`
- `ds-showcase/assets` через alias `@ds-assets`
